## ✨ Destaques do Projeto

Este projeto foi desenvolvido para demonstrar competências avançadas em Frontend, incluindo:

* **⚡ Next.js 14 (App Router):** Estrutura moderna utilizando Server Components por padrão.
* **🎨 UI Design Moderno:** Estética "Dark Mode" com efeitos de Glassmorphism e gradientes neon, seguindo tendências de 2025.
* **🧩 Bento Grid Layout:** Seção de features utilizando CSS Grid complexo e responsivo.
* **✨ Animações Interativas:** Uso de `Framer Motion` para entradas suaves e micro-interações.
* **💰 Lógica de Estado:** Seção de preços com alternância dinâmica (Mensal/Anual) via React State.
* **📱 Mobile-First:** Menu responsivo (Drawer) e adaptação perfeita para telas pequenas.
* **🚀 SEO & Performance:** Metatags configuradas e otimização para Lighthouse (Core Web Vitals).

## 🚀 Como rodar localmente

Clone o projeto e instale as dependências:

```bash
# Clone o repositório
git clone [https://github.com/SEU-USUARIO/taskmaster-landing.git](https://github.com/SEU-USUARIO/taskmaster-landing.git)

# Entre na pasta
cd taskmaster-landing

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
```
